# Datos para preparar un presupuesto

Imagina que trabajas por tu cuenta y preparas un presupuesto para un encargo.
Todos los datos de esta ficha son ficticios. No necesitas utilizar información
personal ni datos de clientes reales.

## El encargo inicial

El trabajo requiere 18 horas y tiene 150 EUR de costes directos. Usa los valores
de la tabla y comprueba los que ya aparezcan en la calculadora antes de obtener
el presupuesto.

| Dato | Valor |
| --- | --- |
| Objetivo mensual neto | 2.000 EUR |
| Costes fijos mensuales | 350 EUR |
| Horas facturables al mes | 80 h |
| Horas estimadas del proyecto | 18 h |
| Buffer de revisiones e imprevistos | 15 % |
| Costes directos del proyecto | 150 EUR |
| Reserva fiscal orientativa | 20 % |
| Recargo sobre el precio mínimo | 10 % |
| Añadir IVA en esta simulación | Sí |

Estos datos describen un caso hipotético; no son una recomendación de precios
ni indican qué tratamiento fiscal debes aplicar a un trabajo real.
